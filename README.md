## 📖 Overview

This portfolio serves as my professional online presence. It highlights my skills, projects, education, and contact information in a clean, premium interface. The design follows a **mobile-first** approach and uses **CSS custom properties** for consistent theming.

**Key goals:**
- Showcase front-end development expertise
- Provide recruiters with a quick overview of my profile
- Demonstrate responsive design and modern UI/UX principles

---

## ✨ Features

- ✅ **Full responsive** — mobile, tablet, desktop
- ✅ **Sticky navigation** with smooth scrolling
- ✅ **Glassmorphism** cards and modern design
- ✅ **Subtle CSS animations** (fade-in, slide-up, hover effects)
- ✅ **Custom CSS variables** for easy theming
- ✅ **Semantic HTML5** for accessibility & SEO
- ✅ **No external dependencies** (pure HTML + CSS)
- ✅ **Production-ready** code with proper comments
